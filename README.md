# Site — Raziel

Instrutor de natação infantil, hidroginástica e personal trainer na Aquarius Academia (Várzea Grande-MT).

Site estático (HTML, CSS e JavaScript, sem build) publicado no GitHub Pages:
https://vitormorilho.github.io/raziel
